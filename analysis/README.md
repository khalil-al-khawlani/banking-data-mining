Banking dataset analysis (Group 1)

Files included:
- `banking_analysis.Rmd`: RMarkdown notebook with initial data understanding steps.
- `packages.R`: helper script to install required R packages.

How to run locally (RStudio):
1. Open RStudio in the repository root.
2. Run `source('analysis/packages.R')` to install required packages.
3. Open `analysis/banking_analysis.Rmd` and click Knit to render HTML.

How to open in Posit Cloud (recommended by course):
1. Push this repository to GitHub.
2. In Posit Cloud, choose New Project -> From Git -> paste the GitHub repo URL.
3. Open `analysis/banking_analysis.Rmd` and run.

Git push example:
```bash
git add analysis/
git commit -m "Add initial banking analysis RMarkdown"
git push origin main
```
